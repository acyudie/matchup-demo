# 매치업 대전 — 우리 동네 전문가 매칭 (시연용 데모)

> ※ 시연용 데모 (가상 서비스) — 등장하는 업체·인물·후기·수치는 모두 가상입니다.

로컬 전문가 매칭 플랫폼의 핵심 흐름(요청서 작성 → 견적 비교 → 채팅 상담·고용)을 클릭해 볼 수 있는 웹 프로토타입입니다.

## 페이지

| 파일 | 내용 |
| --- | --- |
| `index.html` | 메인 — 서비스 검색(자동완성), 인기 카테고리, 이용 방법 3단계, 추천 전문가, 이용 후기, CTA |
| `request.html` | 3단계 견적 요청서 — 서비스 선택 → 상세 질문(단일·복수 선택) → 지역·일정 → 완료 화면, 진행률·입력 검증 |
| `quotes.html` | 받은 견적 — 필터·정렬, 견적 카드 5개, 채팅형 상세 드로어(빠른 질문·자동 응답), 고용 확인 |

## 기술 구성

- 정적 HTML / CSS / Vanilla JS (프레임워크·빌드 도구 없이 바로 실행)
- 글꼴: Pretendard (jsDelivr CDN)
- 모바일 우선 반응형 — 390px ~ 1440px 확인
- 디자인 토큰(CSS 변수)으로 색상·간격·라운드·그림자 통일
- 아이콘: Lucide (ISC License) / 일러스트·아바타: AI 생성 이미지 (실존 인물 아님)
- 요청서 내용은 브라우저 localStorage에만 저장되며 어디에도 전송되지 않습니다.
